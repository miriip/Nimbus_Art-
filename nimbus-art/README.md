# Nimbus Art - Página Web

Página web oficial de Nimbus Art, especializada en cuadros iluminados con estilo cósmico y futurista.

## 🚀 Tecnologías

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## 📦 Instalación

```bash
npm install
```

## 🛠️ Desarrollo

```bash
npm run dev
```

## 🏗️ Build para Producción

```bash
npm run build
```

## 📤 Deploy en Vercel

1. Instala Vercel CLI:
```bash
npm i -g vercel
```

2. Deploy:
```bash
vercel
```

O conecta tu repositorio de GitHub directamente en [Vercel](https://vercel.com).

## 🎨 Características

- Diseño responsive
- Animaciones suaves con Framer Motion
- Fondo cósmico animado con partículas estelares
- Estilo neon con gradientes (cyan → blue → pink → purple)
- Secciones: Hero, About, Gallery, Social Links
